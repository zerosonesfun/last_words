# Reporting a vulnerability

Please do not open a public issue for a security bug.

If this repository has private security advisories enabled, use those. Otherwise, contact the maintainer of the installation you are testing, or the person named in that repository's profile, and wait for them to acknowledge it before you describe the details in public.

Include the version, a short description of the impact, and enough detail to reproduce the issue. Please avoid sending live recovery keys, trusted person keys, SMTP passwords, or message text.

There is no bug bounty.
